# Experiment 06 — Statistical Analysis

## Objective
Calculate descriptive statistics for a sample dataset and visualize the distribution.

## Requirements
- Python 3.9 or newer
- Packages listed in `requirements.txt`

## Run on Windows
1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Install packages:
   ```bash
   py -m pip install -r requirements.txt
   ```
4. Run the program:
   ```bash
   py experiment6.py
   ```

If `py` is not recognized, try `python` instead.

## Output
The program prints count, mean, median, mode, minimum, maximum, range, variance, standard deviation, and quartiles. It also displays and saves a histogram and box plot.

## Customizing the dataset
Edit the `data` dictionary in `experiment6.py` and change the student names and marks.
